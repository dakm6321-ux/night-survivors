# ⚔️ 나이트 서바이버 (Night Survivors) v4.7.3 공식 웹사이트 & 게임 매뉴얼

모바일 가상 조이스틱과 PC 키보드를 완벽 지원하는 웹 기반 **16비트 레트로 픽셀 로그라이트 서바이벌 게임** 공식 포털 웹사이트 및 게임 매뉴얼입니다.

---

## 🎮 최신 v4.7.3 핵심 시스템 & 밸런스 패치 노트

### 1. 💀 8분 최종보스 [사신] & 전설보주 결전 시스템
- **8분 최종보스 [사신] 강림:**
  - 생존 시간 **8분(480초)** 도달 시 화면 경고 배너 **'최종보스 출현 !'**과 함께 거대한 낫을 든 사신(Reaper)이 강림합니다.
  - **사신 결전 전용 필드:** 사신 출현 시 필드의 모든 잡몹과 보스가 즉시 소멸하며, 신규 스폰이 전면 차단되어 사신과의 1:1 진검승부에 집중할 수 있습니다.
  - **도망 불가 맹렬 추적 AI:** 사신의 기본 이동속도는 **360 px/s**이며, 캐릭터의 이동속도보다 항상 최소 15% + 30 px/s 빠르게 설정되어 도망칠 수 없습니다. 또한 넉백과 빙결에 완전 면역입니다.
  - **체력 & 공격력 스케일링:**
    - 체력: 플레이어가 지금까지 가한 **총 누적 피해량의 11배**로 자동 계산됩니다.
    - 공격력: **캐릭터 현재 최대 체력의 44%**에 달하는 치명적인 참격을 가합니다.
  - **사망 공략 힌트:** 사신 출현 후 캐릭터가 사망할 경우 게임 오버 화면에 **'맵을 잘 살펴보면?'**이라는 공략 힌트가 출력됩니다.

- **유한 맵 경계 (4800 x 4800) & 4대 고대 보주조각상자:**
  - 맵 끝자락에 고대 룬 결계벽이 생성되며 캐릭터는 중앙 `(0, 0)`에서 전투를 시작합니다.
  - 중앙 기준 맵 끝 상(북)·하(남)·좌(서)·우(동) 제단에 4개의 **보주조각상자**가 숨겨져 있습니다. (획득 창에 위치 스포일러 힌트가 없으므로 직접 탐색하는 재미를 제공합니다.)
  - 4개의 조각을 모두 모아 레벨 4가 되는 순간 즉시 **'전설보주'**로 진화 각성합니다.

- **✨【전설보주의 절대 신성 가호 & 100배 공격력】:**
  - **절대 방어:** 전설보주 보유 시 사신의 일격 피해를 완벽 차단하여 **오직 1의 스크래치 피해(-1 HP)**만 받습니다.
  - **100배 극딜:** 전설보주를 보유한 상태에서 사신을 타격할 때 모든 무기 및 마법 피해량이 **정확히 100배(10,000%)**로 폭증합니다.

### 2. 🏆 승리 축하 게임 클리어 모달 (Game Clear)
- **사신 토벌 성공 연출:** 사신을 처치하면 승리 팡파르 사운드와 함께 폭죽 파티클이 터지며 전용 **GAME CLEAR** 축하 모달이 팝업됩니다.
- **종합 전투 기록:** 생존 시간, 최종 레벨, 총 처치 수, 최고 DPS, 전설보주를 포함한 최종 초월 무기 빌드가 표시됩니다.
- **메인 화면 이동 & 재도전 버튼:**
  - **[🏠 메인 화면으로 (MAIN MENU)]**: 클릭 시 게임을 초기화하고 타이틀 메인 화면으로 안전하게 복귀합니다.
  - **[🔄 다시 플레이]**: 즉시 새로운 서바이벌 도전을 시작합니다.

### 3. 🎯 과도한 스킬 넉백 밸런스 정밀 조정 (v4.7.3 신규)
- **스킬 넉백 수치 최적화:**
  - **빛의 방패 / 이지스의 천벌:** 6.0 ➔ **2.4** (회전 방패가 적을 화면 밖으로 과도하게 튕겨내던 현상 해결)
  - **성기사의 기도 / 대천사의 강림:** 5.5 ➔ **2.4**
  - **급소 절단 / 공허의 암살:** 6.0 ➔ **2.5**
  - **정의의 망치:** 5.0 ➔ **2.6**
  - **메테오 스트라이크 / 초신성:** 6.0 ➔ **2.8**
  - **마나 격류 / 절대영도 빙하:** 5.0 ➔ **2.4**
- **전투 타격감 안정화:** 적이 무기 사거리 밖으로 너무 멀리 날아가지 않고 자연스럽게 밀려나도록 최대 넉백 상한선을 38px로 제한하여, 근접 공격과 성역 오라의 후속 연계 공격이 안정적으로 적중합니다.

### 4. 👑 45초 주기 보스 몬스터 시스템 & UI 강화
- **보스 체력 난이도 하향 (~47% 조정):**
  - 거대 구울(45초): 1,800 ➔ **950**
  - 골렘 군주(90초): 3,800 ➔ **2,000**
  - 리치 드래곤(135초): 7,200 ➔ **3,800**
  - 파멸 학살자(180초): 14,000 ➔ **7,500**
  - 초중반 무기 빌드 완성 전에도 피로감 없이 시원하게 격파할 수 있습니다.
- **상단 전용 대형 보스 체력바 HUD (`activeBossBarContainer`):** 보스가 출현하면 화면 상단에 웅장한 보스 이름과 실시간 HP 게이지가 고정 표시됩니다.
- **화면 외곽 보스 추적 레이더 화살표:** 보스가 화면 테두리에 있을 때 붉은 경고 화살표(`⚠️ [보스 이름] (거리m) ➔`)가 방향과 거리를 실시간으로 안내합니다.
- **보스 장애물 돌파 & 즉시 워프:** 보스는 나무나 바위에 끼이지 않고 전진하며, 화면 밖으로 멀어질 경우 즉시 플레이어 시야 전방(20px)으로 워프 재배치됩니다.

### 5. 📈 캐릭터 성장 & 서스테인 밸런스
- **레벨업 시 최대 체력 영구 +1 증가:** 일반 레벨업과 만렙 자동 레벨업 모두 레벨이 1 오를 때마다 캐릭터의 **최대 체력(`maxHp`)이 영구 +1 증가**하며 현재 체력도 함께 회복됩니다.
- **적들의 체력 회복 물약 드랍율 13% 상향:** 일반 적 처치 시 회복 포션 드랍율이 **13%**로 대폭 상향되어 무리 전투 유지력을 확실하게 확보했습니다. (보스는 25% 유지)
- **만렙 후 자동 공격력 증가폭 상향 (+20%):** 모든 스킬 마스터 후 레벨업당 공격력 증가 능력이 팝업 없이 **+20%씩 자동 누적**되어 후반부 적들의 체력에 대항할 수 있습니다.

### 6. ⚡ 60 FPS 방어 엔진 최적화 (16배 성능 향상)
- **적 개체수 상한선 (`MAX_ENEMIES = 150`):** 화면에 공존할 수 있는 최대 적 수를 150마리로 제한하여 중후반부 프레임드랍을 원천 차단했습니다.
- **경험치 보석 자동 압축 (`MAX_GEMS = 160`):** 필드 보석이 160개를 초과하면 경험치 손실 없이 기존 보석의 가치로 자동 누적 합산됩니다.
- **AABB 1차 고속 필터링:** 무기 판정 시 무거운 제곱근 계산 전 사각형 범위 체크를 거쳐 충돌 연산 부담을 90% 이상 덜어냈습니다.

## 🕹️ 조작법 안내

### 모바일 터치
- 화면 아무 곳이나 터치하여 드래그하면 **가상 16비트 조이스틱**이 활성화됩니다.
- 손을 떼면 이동을 멈춥니다.
- 모든 공격과 스킬은 사거리 내의 적을 **100% 자동 조준하여 발사**합니다.

### PC 키보드
- **이동:** <kbd>W</kbd>, <kbd>A</kbd>, <kbd>S</kbd>, <kbd>D</kbd> 또는 방향키 (<kbd>↑</kbd>, <kbd>←</kbd>, <kbd>↓</kbd>, <kbd>→</kbd>)
- **레벨업 카드 선택:** 숫자키 <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd>
- **선택 확정:** <kbd>Enter</kbd> 또는 <kbd>Space</kbd>
- **일시정지 / 닫기:** <kbd>Esc</kbd>
